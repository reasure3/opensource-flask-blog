현재 pytest 테스트가 작성되어 있어.
`notes.note_service.NoteService.validate_note_input` 메서드만 구현해서
현재 failing test를 통과하도록 해줘.

조건:
- 테스트 코드는 수정하지 말아줘.
- 기존 클래스/메서드 시그니처는 유지해줘.
- 최소한의 구현으로 테스트를 통과시키는 것을 목표로 해줘.
- 아직 리팩터링은 하지 말아줘.
- 반환 타입은 `ValidationResult`를 사용해줘.
- 에러 코드는 `ErrorCode` enum 값을 사용해줘.

구현해야 하는 규칙:
1. title이 None이면 TITLE_REQUIRED
2. title이 빈 문자열이거나 공백만 있으면 TITLE_REQUIRED
3. title 길이가 최대 길이(기본 50)를 초과하면 TITLE_TOO_LONG
4. content가 None이면 CONTENT_REQUIRED
5. content가 빈 문자열이거나 공백만 있으면 CONTENT_REQUIRED
6. content 길이가 최대 길이(기본 200)를 초과하면 CONTENT_TOO_LONG
7. 모든 조건을 만족하면 is_valid=True, errors=[]

추가 조건:
- 불필요한 구조 변경은 하지 말아줘.
- 테스트를 통과시키는 범위 내에서만 구현해줘.
- 최종 출력은 수정된 프로덕션 코드만 보여줘.
