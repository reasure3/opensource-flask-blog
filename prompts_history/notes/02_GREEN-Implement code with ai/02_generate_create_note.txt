현재 pytest 테스트가 작성되어 있어.
`notes.note_service.NoteService.create_note` 메서드만 구현해서
현재 failing test를 통과하도록 해줘.

조건:
- 테스트 코드는 수정하지 말아줘.
- 기존 인터페이스와 시그니처는 유지해줘.
- 최소 구현으로 테스트를 통과시키는 것이 목표다.
- 아직 리팩터링은 하지 말아줘.

계약:
- 입력은 `NoteCreateRequest`
- 반환은 `Note`
- 유효한 입력이면 새 Note를 생성해서 반환해야 한다.
- 생성된 Note는 정수형 id를 가져야 한다.
- 생성된 Note의 title, content는 요청값과 같아야 한다.
- 내부적으로 `validate_note_input` 규칙을 만족해야 한다.
- 유효하지 않은 입력이면 테스트가 기대하는 방식으로 실패해야 한다.

추가 조건:
- 초기에는 in-memory list 기반으로 구현해줘.
- id는 현재 저장된 노트 기준으로 증가시키면 된다.
- 최종 출력은 수정된 프로덕션 코드만 보여줘.
