pytest 프레임워크를 사용해서 `client_validation.NoteFormSpec` 클래스의 `get_rules` 및 `get_error_messages` 메서드에 대한 유닛 테스트 코드를 작성해줘.

조건:
- 프로덕션 코드는 구현하지 말고, 테스트 코드만 작성.
- pytest 스타일로 작성.
- 테스트는 외부에서 보이는 반환값만 검증.
- 각 테스트는 하나의 규칙만 검증하도록 분리.

현재 계약(인터페이스):
- 클래스: `NoteFormSpec`
- 생성자:
  - `NoteFormSpec(title_max_length=50, content_max_length=200)`

메서드:
1. `get_rules() -> ClientValidationRules`
2. `get_error_messages() -> dict[str, str]`

`ClientValidationRules` 계약:
- `title_required == True`
- `content_required == True`
- `title_max_length == 50`
- `content_max_length == 200`

동작 규칙:
1. 기본 생성자로 만든 경우 `get_rules()`는 필수 여부와 기본 길이 제한을 반환해야 한다.
2. 생성자에서 다른 길이 제한을 주면 `get_rules()` 결과에 반영되어야 한다.
3. `get_error_messages()`는 title/content 필수 오류 메시지와 길이 초과 오류 메시지를 포함해야 한다.

추가 요구사항:
- 기본값 테스트와 사용자 지정값 테스트를 모두 포함해줘.
- 에러 메시지 딕셔너리는 필요한 키가 포함되어 있는지를 검증해줘.
- 최종 출력은 바로 저장 가능한 pytest 테스트 코드만 보여줘.
