pytest 프레임워크를 사용해서 `notes.note_service.NoteService.create_note` 메서드에 대한 유닛 테스트 코드를 작성해줘.

조건:
- 프로덕션 코드는 구현하지 말고, 테스트 코드만 작성.
- 테스트는 pytest 스타일로 작성.
- 각 테스트는 하나의 동작 또는 규칙만 검증하도록 분리.
- 내부 구현이 아니라 외부에서 관찰 가능한 결과만 검증.
- 테스트는 독립적으로 실행 가능해야 함.

현재 계약(인터페이스):
- 클래스: `NoteService`
- 메서드: `create_note(request: NoteCreateRequest) -> Note`
- 입력 DTO:
  - `NoteCreateRequest(title, content)`
- 반환 DTO:
  - `Note(id, title, content)`

동작 규칙:
1. 유효한 title과 content가 들어오면 새로운 Note를 생성해서 반환한다.
2. 생성된 Note는 정수형 id를 가진다.
3. 생성된 Note의 title과 content는 요청값과 동일해야 한다.
4. 내부적으로는 `validate_note_input` 규칙을 만족해야 생성 가능하다.
5. 유효하지 않은 입력이면 생성에 실패해야 한다.

유효하지 않은 입력 예시:
- title이 None
- title이 빈 문자열
- title이 공백만 있음
- title 길이 50자 초과
- content가 None
- content가 빈 문자열
- content가 공백만 있음
- content 길이 200자 초과

추가 요구사항:
- 성공 케이스와 실패 케이스를 모두 포함해줘.
- 실패 케이스에서는 현재 RED 단계이므로, 예외를 기대하거나 생성이 되지 않아야 한다는 계약을 테스트 코드에 반영해줘.
- 테스트 이름은 명확하게 작성해줘.
- 최종 출력은 바로 저장 가능한 pytest 테스트 코드만 보여줘.



-----------------------------------
문제 발생:
NotImplementedError가 발생하면 성공으로 간주하는 테스트 코드 작성
-> 현재 모든 테스트가 성공하는 상황

추가 프롬프트:
`NotImplementedError`를 테스트 코드에 적용하지는 말아줘. 테스트 코드는 완성되어있어야 해.
단, 실제 코드는 구현이 안되어 있으니 테스트를 돌려도 실패가 나는거지




------------------------------
문제 발생:
원래 나야하는 에러 (ValueError)에 대한 검증 코드도 지워버림.

해결: 직접 추가
