현재 pytest와 Flask test client 기반 테스트가 작성되어 있어.
`notes.note_controller.NoteController`의 route 관련 메서드만 구현해서
현재 failing test를 통과하도록 해줘.

조건:
- 테스트 코드는 수정하지 말아줘.
- 기존 route와 메서드 시그니처는 유지해줘.
- 최소 구현으로 테스트를 통과시키는 것이 목표다.
- 아직 리팩터링은 하지 말아줘.

계약:
- GET `/notes` -> 200, 노트 목록 JSON 반환
- GET `/notes/<id>` -> 존재하면 200과 note JSON, 없으면 404와 error JSON
- POST `/api/notes` -> 유효하면 201과 생성된 note JSON
- POST `/api/notes` -> 잘못된 입력이면 400과 errors JSON
- GET `/write` -> 작성 페이지 또는 테스트가 기대하는 응답 반환

추가 조건:
- Flask request/response 처리만 담당하고, 비즈니스 로직은 `NoteService`에 위임해줘.
- HTTP 상태 코드는 테스트가 기대하는 값에 맞춰줘.
- 최종 출력은 수정된 프로덕션 코드만 보여줘.
