pytest 프레임워크를 사용해서 `notes.note_service.NoteService.get_note_by_id` 메서드에 대한 유닛 테스트 코드를 작성해줘.

조건:
- 프로덕션 코드는 구현하지 말고, 테스트 코드만 작성.
- pytest 스타일로 작성.
- 각 테스트는 하나의 경우만 검증하도록 분리.
- 구현 세부사항 대신 반환 결과만 검증.

현재 계약(인터페이스):
- 클래스: `NoteService`
- 메서드: `get_note_by_id(note_id: int) -> Optional[Note]`
- Note는 다음 필드를 가진다:
  - `id: int`
  - `title: str`
  - `content: str`

동작 규칙:
1. 존재하는 note_id를 조회하면 해당 Note 객체를 반환한다.
2. 존재하지 않는 note_id를 조회하면 None을 반환한다.
3. 초기 노트 목록은 `NoteService(initial_notes=[...])` 방식으로 주입할 수 있다.

테스트 시나리오:
1. 초기 노트 목록에 id=1인 노트가 있을 때, `get_note_by_id(1)`은 해당 Note를 반환해야 한다.
2. 여러 개의 노트가 있을 때, 요청한 id에 해당하는 노트만 반환해야 한다.
3. 존재하지 않는 id를 조회하면 None을 반환해야 한다.
4. 빈 노트 목록에서 조회하면 None을 반환해야 한다.

추가 요구사항:
- 성공 케이스와 실패/엣지 케이스를 모두 포함해줘.
- 테스트 함수 이름은 의도가 잘 드러나게 작성해줘.
- 최종 출력은 바로 저장 가능한 pytest 테스트 코드만 보여줘.
